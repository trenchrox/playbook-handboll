# Playbook

Fristående HTML-app för att rita, spara och visa spelmönster i handboll. Tredje appen i
Handbollssviten, vid sidan av Tracker och Teambuilder: en självständig HTML-fil, allt inbäddat,
helt offline, IndexedDB för lagring, JSON-export/import som backup.

- Spec: [`docs/PLAYBOOK_spec_v0.1.md`](docs/PLAYBOOK_spec_v0.1.md) (original: samma namn, `.pdf`)
- App: `playbook.html` (ej byggd än)
- Accentfärg: grön `--save #30d158`

Playbook hanterar taktik, inte personer — brickor etiketteras med position eller nummer, aldrig med
barns namn. Därför är banken ofarlig att exportera och dela, och repot kan vara publikt.
